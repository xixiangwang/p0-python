# p0-python

大模型应用算法方向求职准备的 **P0 阶段**代码仓库。

目标不是"从零学编程"（本科学过 C 和 408），而是把编程语言从 C 换成 Python，
同时补上数据结构手写能力和 LeetCode 入门。

## 环境

- Python 3.11（conda 环境 `p0`）
- 第三方依赖：无，全部只用标准库
- 编辑器：VS Code

## 文件命名规范

- `d<学习日>_<英文关键词>.py` —— 知识点演示代码（例：`d13_hash.py`）
- `lc_<题号>_<中文题名>.py` —— LeetCode 题解（例：`lc_206_反转链表.py`）
- `ds_<结构名>.py` —— 数据结构手写实现（例：`ds_bubble.py`）
- `scores.csv` —— `d9_csv.py` 用到的测试数据

## 各文件对应内容

- `d1_*` ~ `d3_*` —— 基础语法：变量 / 分支 / 循环
- `d4_*` ~ `d5_*` —— list / dict / set / str
- `d6_*` ~ `d7_*` —— 函数 / 推导式 / lambda
- `d8_*` ~ `d9_*` —— 类与 self / 文件 IO / 异常 / 常用库 / csv
- `d10_*` ~ `d11_*` —— 栈 / 队列 / 链表 / 二叉树
- `d12_*` ~ `d13_*` —— 排序（快排 + 归并）/ 哈希表（链地址法）
- `lc_*.py` —— LeetCode 题解
- `ds_*.py` —— 数据结构手写
